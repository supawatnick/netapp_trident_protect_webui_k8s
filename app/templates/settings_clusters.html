How to connect to a different cluster? ▼

To switch to a different cluster, follow these 3 steps. The UI works with both OpenShift and vanilla Kubernetes clusters.

Step 1: Get a bearer token from the target cluster

For OpenShift:

From the cluster's OpenShift web console:

  1. Open the console URL: https://console-openshift-console.apps.<your-cluster-domain>
  2. Login with your credentials (e.g., kubeadmin)
  3. Click your username in the top-right corner
  4. Select "Copy login command"
  5. Click "Display Token"
  6. Copy the token (starts with sha256~)

For vanilla Kubernetes:

From your kubeconfig file (typically ~/.kube/config):

  1. Run: kubectl config view --minify -o jsonpath='{.users[0].user.token}'
  2. Or create a service account token: 
    kubectl create token my-service-account --duration=24h
  3. Copy the token (long base64 string)

Or via CLI on a machine with the right tool configured for that cluster:

# OpenShift
oc login https://api.your-cluster:6443
oc whoami -t

# Vanilla Kubernetes
kubectl config set-credentials myuser --token=<your-token>

Step 2: Add the cluster profile in this UI

  1. Click "+ Add Profile" below
  2. Fill in Profile Name + API URL
  3. Click Save Profile

Step 3: Login & Switch

  1. Click "Login & Switch" on the new profile row
  2. Paste the bearer token from Step 1
  3. Click "Login & Switch"
  4. The active profile switches automatically — no restart needed

Import Kubeconfig ▼

Use this to connect to a vanilla Kubernetes cluster by pasting its kubeconfig file. The kubeconfig will be saved to ~/.kube/config (a backup of any existing file is made first as ~/.kube/config.bak), and a new cluster profile will be created automatically from the current-context.

For OpenShift clusters, you can use the Login & Switch form below with a bearer token instead.
